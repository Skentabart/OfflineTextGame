# OFFLINE GAME V30

Модульная офлайн текстовая игра на Qwen3 через llama.cpp.

## Возможности

- GPU/CPU запуск Qwen
- Whisper CPU
- Windows SAPI TTS
- процедурная генерация мира
- динамические предметы
- сохранение состояния предметов
- динамические события
- шум
- ловушки и опасности
- здоровье и смерть
- враги и бой
- атака, защита, бегство
- преследование
- физические последствия действий
- сохранения

## Установка

```bat
py -3.14 -m pip install -r requirements.txt
run.bat
```

Файл модели должен находиться в `model/Qwen3-1.7B-Q4_K_M.gguf`, сервер llama.cpp в `bin/llama-server.exe`.
